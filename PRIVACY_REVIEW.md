# Privacy policy verification checklist (required before publication)

The NOVA Capsule source ZIP referenced in conversation is a Windows local path, **not a source attachment available for inspection here**. The policy page has therefore deliberately been written as an unapproved draft.

Before using the website's privacy URL in Microsoft Partner Center:

1. Audit media-session access, album artwork, audio endpoint control, timer storage, Bluetooth device discovery, device identifiers and AC/battery event handling.
2. Identify all persistence locations: settings, log files, crash reports, cache, analytics and their retention/deletion behaviour.
3. Audit all HTTP clients, telemetry libraries, update checks, network endpoints and integrations.
4. List third-party SDKs and any information disclosed to them, including Windows Store services if applicable.
5. Clarify whether identifying data is collected/shared or kept locally and how users can exercise deletion/access rights where applicable.
6. Add real version/effective date and publisher contact. Be precise about permissions and optional features.
7. Replace provisional wording in privacy.html with the audited facts and remove the draft banner and `noindex` when approved.
8. Check local applicable legal requirements with a qualified person as appropriate; this is not legal advice.

Until then, do **not** treat `privacy.html` as a finalized Microsoft Store privacy policy.
